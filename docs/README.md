# 🎄크리스마스 프로모션

## 🎯 구현할 기능

### 입출력
- [x] 식당 예상 방문 날짜 입력 받기
- [ ] 주문할 메뉴와 개수 입력 받기
- [ ] '주문 메뉴', '할인 전 총주문 금액', '증정 메뉴', '혜택 내역', '총혜택 금액', '할인 후 예상 결제 금액', '12월 이벤트 배지' 출력 

### 주문 서비스
- [ ] 주문할 메뉴 총 합산 금액 계산

### 할인 서비스
- [ ] 총 주문 만원 이상부터 이벤트 적용
1. 크리스마스 디데이 할인 (1일에서 25일까지만)
- [ ] 1일부터 25일까지 날마다 1,000에서 100원씩 할인 금액 증가(총 주문금액에서 할인)
2. 평일 할인 (일 ~ 목)
- [ ] 디저트 메뉴 1개당 2,023원 할인
3. 주말 할인 (금, 토)
- [ ] 메인 메뉴 1개당 2,023원 할인
4. 특별 할인
- [ ] 일요일과 25일 당일은 총 주문금액에서 1,000원 할인
5. 증정 이벤트
- [ ] 할인 전 총주문 금액이 12만원 이상이면, 샴페인 1개 증정 (= 25,000원 혜택)
6. 총 혜택 금액 (할인 금액의 합계 + 증정 메뉴 가격)
- [ ] 금액에 따라 이벤트 배지 증정(5천원: 별, 1만원: 트리, 2만원: 산타)

### 에러 메시지 출력
- [ ] 공용: "[ERROR]"로 시작.
- `[ERROR] 유효하지 않은 날짜입니다. 다시 입력해 주세요.`
  - [x] 방문 날짜가 1 이상 31 이하의 숫자가 아닌 경우.
- `[ERROR] 유효하지 않은 주문입니다. 다시 입력해 주세요.`
  - [ ] 메뉴판에 없는 메뉴를 입력하는 경우.
  - [ ] 메뉴 형식이 예시와 다른 경우.
  - [ ] 중복 메뉴를 입력한 경우.
  - [ ] 음료만 주문한 경우.
  - [ ] 주문한 메뉴 개수가 20개를 초과한 경우.
