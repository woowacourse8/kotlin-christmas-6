# 🎄 크리스마스 프로모션

## 🚀 기능 목록

### 1. 방문 날짜 (VisitDate)
고객이 식당에 방문할 날짜를 관리하고 검증한다.
- [x] **유효성 검증**: 방문 날짜는 1 이상 31 이하의 숫자여야 한다.
    - *예외*: 숫자가 아닌 문자가 입력된 경우
    - *예외*: 1 미만, 31 초과의 숫자가 입력된 경우
    - *예외*: 공백이 입력된 경우

### 2. 주문 (Order & Menu)
고객이 선택한 메뉴와 수량을 관리하고 주문 규칙을 검증한다.
- [x] **주문 생성**: 메뉴판에 있는 메뉴 이름과 수량을 매핑하여 주문을 생성한다.
- [x] **총 주문 금액 계산**: (메뉴 가격 * 수량)의 총합을 계산한다.
- [x] **주문 유효성 검증**:
    - *예외*: 메뉴판에 없는 메뉴를 입력한 경우
    - *예외*: 메뉴의 개수가 1 이상의 숫자가 아닌 경우
    - *예외*: 형식이 예시와 다른 경우 (예: 구분자 쉼표(,) 누락 등)
    - *예외*: 중복된 메뉴를 입력한 경우
    - *예외 (비즈니스 정책)*: 음료만 주문한 경우
    - *예외 (비즈니스 정책)*: 총 메뉴 개수가 20개를 초과한 경우

### 3. 혜택 정책 (Benefit Policy)
주문 내역과 방문 날짜를 기반으로 적용 가능한 혜택을 계산한다.

**[전제 조건]** 총 주문 금액이 10,000원 이상일 때만 이벤트가 적용된다.

- [x] **크리스마스 디데이 할인**:
    - 기간: 12.1 ~ 12.25
    - 1,000원으로 시작하여 매일 100원씩 할인 금액 증가.
- [x] **평일 할인**:
    - 기간: 12월 중 일요일 ~ 목요일 (25일 포함 여부 로직 확인 필요)
    - 디저트 메뉴 1개당 2,023원 할인.
- [x] **주말 할인**:
    - 기간: 12월 중 금요일, 토요일
    - 메인 메뉴 1개당 2,023원 할인.
- [x] **특별 할인**:
    - 달력에 '별'이 있는 날 (매주 일요일 + 25일 크리스마스)
    - 총 주문 금액에서 1,000원 할인.
- [x] **증정 이벤트**:
    - 할인 전 총 주문 금액이 120,000원 이상일 때 샴페인(25,000원) 증정.

### 4. 이벤트 배지 (Event Badge)
총 혜택 금액(할인 금액 + 증정 메뉴 가격)에 따라 배지를 부여한다.
- [x] **배지 부여 기준**:
    - 5,000원 이상: 별
    - 10,000원 이상: 트리
    - 20,000원 이상: 산타
- [x] 혜택 금액이 기준 미만일 경우 배지는 '없음'이다.

### 5. 입출력 (View)
사용자와 상호작용하며 도메인 로직의 결과를 출력한다.
- [x] **입력 (InputView)**:
    - 방문 날짜 입력 시 안내 메시지 출력 및 입력값 반환.
    - 주문 메뉴 입력 시 안내 메시지 출력 및 입력값 반환.
    - *공통*: `IllegalArgumentException` 발생 시 `[ERROR]` 메시지를 출력하고 해당 부분부터 다시 입력을 받는다.
- [x] **출력 (OutputView)**:
    - 주문 메뉴 목록 출력.
    - 할인 전 총 주문 금액 출력 (천 단위 쉼표 포맷팅).
    - 증정 메뉴 출력 (해당 없으면 "없음").
    - 혜택 내역 출력 (적용된 혜택만 출력, 없으면 "없음").
    - 총 혜택 금액 출력 (음수 표기).
    - 할인 후 예상 결제 금액 출력.
    - 12월 이벤트 배지 출력.
